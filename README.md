# Markdown Local Editor

ブラウザーだけで動く、単一HTMLファイルの簡易Markdownエディターです。
インストールやサーバーは不要で、HTMLファイルをローカルで開いて使用します。

> このリポジトリは遊びで作った個人制作物です。今後の更新、機能追加、不具合修正、サポートは予定していません。

## ファイル

| ファイル | 内容 |
| --- | --- |
| `standard.html` | CommonMark互換の基本記法のみを出力する標準版 |
| `extended.html` | 目次、下線、文字色、取り消し線を追加した独自記法版 |

どちらの版も、編集内容を`.md`または表示用の単体`.html`として保存できます。

## 標準版で使用できる記法

- 見出し
- 本文
- 箇条書き、番号付きリスト
- 太字、斜体
- 引用
- リンク
- インラインコード、コードブロック
- 区切り線

## 独自記法版の追加機能

| 機能 | 記法 | 備考 |
| --- | --- | --- |
| 取り消し線 | `~~文字~~` | GitHub Flavored Markdownなどで利用される拡張 |
| 下線 | `++文字++` | このエディター独自の記法 |
| 文字色 | `{#FF0000\|文字}` | このエディター独自の記法 |
| 目次 | `[[目次]]` | 見出しから自動生成する独自の記法 |

独自記法を含む`.md`ファイルをほかのMarkdownビューアーで開くと、その部分が意図どおり表示されない場合があります。`.html`保存では、これらの表示も反映されます。

## 使い方

1. 使用するHTMLファイルをダウンロードします。
2. ファイルをブラウザーで開きます。
3. 左側で編集し、右側のプレビューを確認します。
4. `.md保存`または`.html保存`を選びます。

各HTMLのページ最下部には、機能別のMarkdownチートシートがあります。ミニプレビューで直接確認できる記法と、保存先のMarkdown表示環境に依存する記法を区別して掲載しています。

入力内容はブラウザーの`localStorage`へ自動保存されます。サーバーへの送信、アクセス解析、外部APIの利用はありません。ブラウザーの保存データを消去すると編集中の内容も失われる可能性があるため、必要な文書はファイルとして保存してください。
